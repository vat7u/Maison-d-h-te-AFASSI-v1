# Reviews section

## Overview

Front-end only reviews section on the home page (`#avis` in `../index.html`,
a navy band reached from the header's "Avis" link). It shows three static
platform rating cards and an endless, slowly scrolling strip of guest reviews
filtered by the site language chosen with the header FR / EN / AR / ES
buttons. Data lives in two plain files, separate from the component, so it
can be replaced without touching the rendering code. Nothing is fetched from
the review platforms.

## Interface

- `ratings.js:window.AFASSI_RATINGS` — array of platform summaries
  `{ platform, name, short?, logo, score, scale, count, url }`. Static, typed
  by hand: Google Reviews 4.8/5, Expedia 9.8/10, Booking.com 9.4/10. `count`
  and `url` are `null` (hidden) until filled in. `logo` is an image URL, for
  now each site's icon from Google's favicon service (built by the
  `ratings.js:favicon(domain)` helper, a top-level script constant); a local
  path such as `images/platforms/booking.svg` works too, and `null` hides it.
- Rating card layout (`renderSummary`): a header with the logo on a white
  tile and the platform name (Montserrat 600, uppercase), a hairline, then the
  score and five gold stars filled to `score / scale`. Cards are navy-800
  panels on the navy band (`../styles.css`, "Rating cards").
- `mock-reviews.js:window.AFASSI_REVIEWS` — `{ isMock, reviews }`. `reviews`
  holds objects `{ id, platform, lang, name, country, rating, text }`.
  **Every current entry is fictional development content** (`isMock: true`).
- `reviews.js` — self-running script (an IIFE, no globals). It renders into
  the elements of `#avis` marked
  `data-reviews="eyebrow|title|summary|marquee|track|list|empty"`:
  - `UI` (`reviews.js:14`) — section wording, number locale and text
    direction for `fr`, `en`, `es`, `ar`. Only this wording is localised; the
    reviews are shown as written.
  - `render(lang)` (`reviews.js:172`) — sets `lang` and `dir` on the section,
    renders the rating cards, the cards whose `lang` equals the site language
    (`reviews.js:180`) into `data-reviews="list"`, and the localised empty
    message (the strip is hidden when there are none).
  - `markLongTexts()` (`reviews.js:133`) — shows "Read more" only on texts
    cut by the 6-line clamp.
  - `fillTrack()` (`reviews.js:143`) — clones the list into the track until
    the band is full (copies get `aria-hidden`, their buttons `tabindex="-1"`),
    sets `--review-shift` to one list width (negative left to right, positive
    for Arabic so the strip travels the other way) and `--review-duration` to
    about 30 px/s, and adds `is-running`. Refills on resize
    (`reviews.js:191`).
  - Read more / less (`reviews.js:162`) — one click handler on the track opens
    any card, original or copy; the track gets `is-paused` while a card is
    open. The strip also pauses on hover and while it holds keyboard focus
    (`../styles.css`, "Review strip").

## Invariants

- Filtering is by each review's original `lang`; reviews are never
  translated or mixed in from another language. A language with no reviews
  shows the localised empty state (`data-reviews="empty"`).
- `review.platform` must match a `platform` key in `AFASSI_RATINGS`; the
  rating scale (5 or 10) and the platform name come from there. An unknown
  key falls back to its raw name and a 5-point scale.
- `review.lang` must be `fr`, `en`, `es` or `ar` (the values of
  `../site.js:SITE_LANGS`); other values are never shown.
- `country` is a two-letter ISO 3166 code. The country name is produced in
  the site language by `Intl.DisplayNames`; the flag comes from
  `flagcdn.com` and is removed if it fails to load.
- While `AFASSI_REVIEWS.isMock` is `true`, each card carries an
  "Exemple / Example / Ejemplo / مثال" badge (`reviews.js:123`); there is no
  section-wide notice. Set it to `false` only once the list contains real,
  authorised reviews.
- Only `data-reviews="list"` is the source; the copies inside the track are
  regenerated by `fillTrack` on every render and resize, never edited.
- With `prefers-reduced-motion: reduce` nothing is cloned or animated; the
  strip becomes a still row the visitor scrolls sideways (`../styles.css`).
- All data is inserted as text (escaped by `esc`), so review text must be
  plain text, not HTML.
- Load order on the home page (`../index.html:322-325`): `site.js` (for
  `getSiteLang` and `observeFades`), then `ratings.js`, `mock-reviews.js`,
  then `reviews.js`.
- Arabic (`ar`) renders right to left (`dir="rtl"` on the section and on each
  Arabic card). Layout styles use logical properties (`inset-inline-start`,
  `margin-inline-start`, `text-align: start`) so they mirror; Arabic text
  uses `--font-arabic` (Noto Naskh Arabic, loaded in `../index.html`) with
  letter-spacing set to 0 (`../styles.css`, "Reviews" block).

## Side Effects

- Re-renders the section when `document` receives `afassi:langchange`
  (`reviews.js:189`), dispatched by `../site.js:setSiteLang`.
- Runs a CSS animation on the track and listens to `resize` on `window`.
- Writes only inside `#avis` (`innerHTML`, `lang`, `dir`, `hidden`).
- Network: flag images from `https://flagcdn.com/`, platform logos from
  `https://www.google.com/s2/favicons` (a logo that fails to load is removed
  with its tile), and the Noto Naskh Arabic font from Google Fonts. No
  platform API calls, no storage of its own.

## Verification

- Run: `<test-command>` (no automated test suite is configured).
- Manual check: serve the folder (`python -m http.server 5500`), open `/`,
  scroll to the reviews, and click FR, EN, AR and ES: each shows only reviews
  in that language, and AR mirrors the layout right to left.
