# Journal (blog)

Before reading or changing anything in this folder, read [README.md](README.md).
It is this folder's contract: the post format in `posts.js`, the helpers in
`blog.js`, and the invariants you must keep (unique `slug`, `YYYY-MM-DD`
dates, plain-text post fields, `posts.js` loaded before `blog.js`).

@README.md

If a change alters what README.md describes (a new post field, helper, rule or
side effect), update README.md in the same change.
